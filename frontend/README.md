# Auction House frontend

React + TypeScript + Vite. Initial screens: registration/login, public lot
listing/details, own wallet and simulated bidder deposits. Seller tools and
bidding are not available yet.

Run the full app with `docker compose up --build -d` from the repository root,
then open http://127.0.0.1:5175. See [development](../docs/development.md#initial-frontend)
for host commands/tests and [API contracts](../docs/api.md).
